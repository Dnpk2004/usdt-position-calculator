# USDT 永续合约快速仓位计算器 V1.0

## 项目解决什么问题

交易前，用户通常已经在图表上确定开仓价和止损价，但还需要根据自己愿意承担的亏损额换算下单数量。本工具让用户输入交易方向、开仓价、止损价和计划止损亏损，立即得到对应的 USDT 仓位价值与币种数量，并估算初始保证金和强平价格。它是适用于 Windows 电脑浏览器的简体中文独立工具。**不连接币安账户，不获取实时行情，不自动交易，不需要 API Key。**

## 主要功能

- 支持做多、做空；BTC、ETH、SOL、BNB、XRP 快捷选择和手动输入币种。切换币种会清空旧价格。
- 开仓价、止损价、可选止盈价和风险金额实时计算；止损/止盈价格与百分比双向联动。
- 同等突出显示仓位名义价值和开仓数量，分别支持一键复制；同时显示止损亏损、止盈收益和盈亏比。
- 支持逐仓与简化全仓。逐仓可手动输入杠杆、使用快捷倍数或应用最高参考/保守推荐杠杆；全仓需输入钱包余额才能估算强平价。
- 显示简化预估强平价与风险状态；维持保证金率、扣减额和额外安全缓冲可调整。结果仅供参考。
- 使用浏览器本地存储恢复最近有效参数，支持一键重置。

## 安装方法

需要 Node.js 24 LTS（至少 24.14）和 npm。在项目目录打开 PowerShell，首次运行：

```powershell
npm install
```

安装完成后可使用下方任一启动方式。依赖已安装时，本地计算与设置保存不需要网络。

## 使用方法

### 平时双击启动（不需要 ChatGPT）

依赖已安装后，在资源管理器中打开项目目录，双击 **启动计算器.cmd**。它会启动本地服务并在默认浏览器打开 [http://127.0.0.1:5173](http://127.0.0.1:5173)。如果计算器已在运行，则直接打开页面，不重复启动。

使用期间保持启动窗口运行；关闭窗口即停止本地服务。下次使用再次双击即可，不需要打开 ChatGPT，也不需要联网。可右键此文件选择“发送到 → 桌面快捷方式”（Windows 11 可先点“显示更多选项”），方便从桌面启动。也可将启动文件复制到桌面：当旁边没有项目文件时，它会自动查找当前用户的 `Documents\ChatGPT\bian` 项目目录。请保留整个项目文件夹。

### 命令行启动

在项目目录打开 PowerShell：

```powershell
npm run dev
```

在浏览器打开终端打印的地址，默认 [http://127.0.0.1:5173](http://127.0.0.1:5173)。若端口占用，Vite 会打印新的端口。开发服务仅监听本机。

```powershell
npm run typecheck    # TypeScript / Vue 类型检查
npm test             # 所有 Vitest 测试，执行后退出
npm run test:watch   # 持续测试
npm run build        # 类型检查后生成 dist/
npm run preview      # 本地预览构建产物，默认 http://127.0.0.1:4173
```

请通过本地 HTTP 服务使用，勿直接双击 dist/index.html。localStorage 和剪贴板权限由浏览器决定；被禁用时页面会明确提示，计算仍可使用。

### 页面操作

1. 选择币种、交易方向和保证金模式。首次没有默认行情，价格全部手动输入。
2. 输入开仓价格、止损价格或距离、计划止损亏损（默认 50 USDT）。止盈可留空。
3. 实时查看仓位名义价值、币种数量和初始保证金。两个主要结果可独立复制完整计算值，无千分位或单位；数量未按交易所下单步长取整。
4. 在逐仓模式可应用最高参考或保守推荐杠杆，也可自由输入 1–125 范围内的小数倍数。推荐只扫描整数。全仓模式填写钱包余额后才估算强平价，不套用逐仓杠杆推荐。

切换币种清空所有价格，防止沿用其他币种价格。手动币种仅作理论标记，不验证合约是否存在。切换方向保留有效止损/止盈距离并映射到反向价格。开仓价格变化时，最后编辑价格则保留绝对价格，最后编辑百分比则保持百分比；被编辑的输入不实时格式化，避免小数输入光标跳动。

设置仅保存在当前浏览器、当前来源的 localStorage，含币种、方向、模式、风险、杠杆、缓冲、估算假设、全仓余额和最近一组有效交易价格。无效价格草稿不会覆盖有效交易快照，币种切换立即清掉价格快照。重置清除设置并恢复默认值：BTC、做多、逐仓、50 USDT 风险、10 倍杠杆、50% 缓冲、MMR 0.5%、扣减额 0。

## 输入输出示例

选择 **BTCUSDT、做多、逐仓**，输入开仓价 **100000 USDT**、止损价 **98000 USDT**、止盈价 **104000 USDT**、计划止损亏损 **50 USDT**，杠杆设为 **10 倍**。保持默认额外缓冲 **50%**、参考维持保证金率 **0.5%**、扣减额 **0 USDT**。页面计算得到：

| 输出 | 结果 |
| --- | ---: |
| 仓位名义价值 | 2,500.00 USDT |
| 开仓数量 | 0.025 BTC |
| 理论初始保证金 | 250.00 USDT |
| 止损距离、理论止损亏损 | 2%、50.00 USDT |
| 预计止盈收益、盈亏比 | 100.00 USDT、2 : 1 |
| 最高参考杠杆、保守推荐杠杆 | 40×、28× |
| 简化预估强平价 | 90,452.26 USDT |

本例的强平价与推荐倍数只基于上述本地模拟参数，不是币安实时数据。实际可下单数量还需遵守交易对的数量步长和最小名义价值等规则。

## 计算方法

令 E 为开仓价，S 为止损价，T 为止盈价，R 为计划亏损，L 为杠杆，Q 为正数币种数量：

```text
D = |E − S|
止损距离百分比 = D / E × 100
Q = R / D
仓位名义价值 N = Q × E
理论初始保证金 I = N / L
理论止损亏损 = Q × D
做多止盈盈利 = Q × (T − E)
做空止盈盈利 = Q × (E − T)
盈亏比 = 止盈盈利 / 理论止损亏损
```

固定开仓价、止损价、风险金额后，改变杠杆**不改变数量与名义价值**，只改变理论初始保证金。风险金额不包括手续费、滑点、资金费，实际亏损不保证等于设定金额。错误的可选止盈仅阻止收益与盈亏比显示，不影响有效仓位。

核心使用独立 decimal.js 构造器、80 位有效数字计算输出，不在计算中提前按显示精度取整。强平位置、推荐与余额是否足够的判断使用原始有限十进制数的交叉乘积（768 位运算精度覆盖受限输入的多项式运算），避免循环小数末位舍入改变边界。价格联动使用 256 位精度；价格来源的派生百分比仅显示 12 位有效数字，仍按原价格计算，切换方向直接镜像价差。输入绝对值范围为 1e-24 至 1e18，允许科学计数法；允许为零的参数包括 MMR、扣减额、余额和缓冲。参考 MMR 必须小于 100%，缓冲范围 0–10000%。超过输入长度/幅度或理论仓位上限（1e18 USDT，数量 1e24）明确拒绝；小于 0.01% 的止损距离另作提示。这些是计算器本地边界，非交易所限制。

金额显示两位小数；不足 0.01 的正金额显示 `<0.01`。数量最多八位小数，极小正数显示 `<0.00000001` 并提示精度不足。价格保留自适应精度，低价不会显示成真实零。复制保留完整计算精度。

## 简化强平模型与参考杠杆

依据币安官方机制中的 `维持保证金 = 名义价值 × MMR − Maintenance Amount`，本工具固定一个档位，令 r 为参考 MMR、C 为参考扣减额、M 为支持仓位的保证金余额。

```text
做多权益(P) = M + Q × (P − E)
做空权益(P) = M + Q × (E − P)
维持保证金(P) = Q × P × r − C

令权益(P) = 维持保证金(P)：
做多 P = (Q × E − M − C) / (Q × (1 − r))
做空 P = (Q × E + M + C) / (Q × (1 + r))
```

逐仓 M = I，全仓 M = 用户输入的全仓钱包余额。全仓钱包余额、仓位和假设不变时，改变杠杆不改变该模型的强平价。余额未填写、无效或不足以覆盖初始保证金时为灰色，不给出安全结论，基础仓位仍正常计算。

**默认 r = 0.5%、C = 0 USDT 是本地模拟参数，不代表币安任一交易对的真实最新档位。** 可在“估算假设”中修改，不读取实际档位或实际可用杠杆。只模拟一笔线性 USDT 合约，无其他仓位、挂单、负债、额外保证金、手续费或资金费；开仓时未实现盈亏为零。

无有限正价格解显示“当前假设下无有效正价格强平估算”。参数造成负维持保证金时同样不作估算或安全结论。开仓权益已不足维持保证金时标红。所有结果标注“简化预估”。

设 B 为止损距离乘以缓冲比例。逐仓模式从 1 到 125 倍枚举整数，取满足条件的最大倍数：

- 最高参考：做多 P < S，做空 P > S；等于止损按红色处理。
- 保守推荐：还需做多 P ≤ S − B，做空 P ≥ S + B。
- 无正价格有效解、开仓已不足维持保证金的倍数不参与推荐。没有满足条件的倍数时明确显示无推荐。
- 绿：满足额外缓冲；黄：强平价仍在止损之外但缓冲不足；红：进入止损区域或开仓权益不足；灰：无法可靠计算。**颜色不是交易安全保证。**

1–125 倍只是本地扫描范围，不代表币安每个币种允许的杠杆。用户可选模型判断为红色的倍数，工具警告但不阻止。

币安使用**标记价格**触发强平，止损可能采用不同价格源、并发生跳空或滑点。真实档位会随交易对和强平点名义价值变化；其他持仓、追加保证金、资金费用等都会导致偏离，因此不保证与币安强平价一致，也不保证止损先于强平成交。

官方参考（开发核对日期 2026-11-10）：[USDⓈ-M 强平价计算机制](https://www.binance.com/en/support/faq/detail/b3c689c1f50a44cabb3a84e663b81d93)、[币安强平协议与标记价格](https://www.binance.com/en/support/faq/detail/360033525271)。这些说明用于核对机制，本工具未获取实时档位。

## 文件组织

- `src/core/calculator.ts`：输入校验、仓位/盈亏、强平模型和逐仓杠杆枚举。
- `src/core/format.ts`：结果显示精度。
- `src/state.ts`：输入联动、最近有效参数持久化。
- `src/App.vue`、`src/components/NumberField.vue`、`src/style.css`：界面。
- 相邻 `*.test.ts`：可复现的公式、边界、状态与页面行为测试。
